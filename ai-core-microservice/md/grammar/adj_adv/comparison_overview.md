# CÁC CẤU TRÚC SO SÁNH (COMPARISON)

Để dùng đúng so sánh, AI cần phân biệt được Tính từ/Trạng từ **Ngắn** (1 âm tiết) và **Dài** (2 âm tiết trở lên).

## 1. SO SÁNH BẰNG (EQUALITY)
*   **Cấu trúc:** `as + adj/adv + as`
*   **Ví dụ:** She is **as tall as** her brother.

## 2. SO SÁNH HƠN (COMPARATIVE)
*   **Tính từ ngắn:** `adj + er + than` (Faster than).
*   **Tính từ dài:** `more + adj + than` (More beautiful than).
*   **Ví dụ:** This task is **more difficult than** the previous one.

## 3. SO SÁNH NHẤT (SUPERLATIVE)
*   **Tính từ ngắn:** `the + adj + est` (The fastest).
*   **Tính từ dài:** `the most + adj` (The most beautiful).
*   **Ví dụ:** It is **the most expensive** car in the world.

## 4. SO SÁNH KÉP (DOUBLE COMPARISON)
Cấu trúc "Càng... càng...", cực kỳ quan trọng cho Band 7.0+.
*   **Cấu trúc:** `The + comparative, the + comparative`
*   **Ví dụ:** **The more** you practice, **the better** you become.
*   **Ví dụ (IELTS):** **The higher** the demand, **the more expensive** the product becomes.

## 5. CÁC TRƯỜNG HỢP BẤT QUY TẮC
*   Good/Well -> better -> the best
*   Bad/Badly -> worse -> the worst
*   Far -> farther/further -> the farthest/furthest
*   Little -> less -> the least
*   Many/Much -> more -> the most
