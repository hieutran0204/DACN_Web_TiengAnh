# ĐẢO NGỮ CÂU ĐIỀU KIỆN (CONDITIONAL INVERSION)

Thay thế "If" bằng cách đảo trợ động từ lên đầu câu để câu văn trang trọng hơn.

## 1. ĐẢO NGỮ LOẠI 1 (DÙNG SHOULD)
*   **Cấu trúc:** `Should + S + V (nguyên mẫu), S + will + V`
*   **Ví dụ:** If you have any questions... -> **Should you have** any questions, please contact me.

## 2. ĐẢO NGỮ LOẠI 2 (DÙNG WERE)
*   **Trường hợp có động từ Be:** `Were + S + ..., S + would + V`
    * *Ví dụ:* If I were rich... -> **Were I rich**, I would travel the world.
*   **Trường hợp có động từ thường:** `Were + S + TO V, S + would + V`
    * *Ví dụ:* If I lived here... -> **Were I to live** here, I would be happy.

## 3. ĐẢO NGỮ LOẠI 3 (DÙNG HAD)
*   **Cấu trúc:** `Had + S + V3, S + would have + V3`
*   **Ví dụ:** If we had known... -> **Had we known** the truth, we would have acted differently.

## 4. LƯU Ý VỚI CÂU PHỦ ĐỊNH
Khi đảo ngữ, từ "NOT" luôn đứng sau chủ ngữ, không viết tắt.
*   *Sai:* Hadn't I known...
*   *Đúng:* **Had I not known**...
