# CÂU ĐIỀU KIỆN LOẠI 0 & 1 (CONDITIONALS TYPE 0 & 1)

## 1. LOẠI 0 (ZERO CONDITIONAL)
*   **Cách dùng:** Diễn tả một chân lý, sự thật hiển nhiên hoặc một thói quen cố định.
*   **Công thức:** `If + S + V1 (hiện tại đơn), S + V1 (hiện tại đơn)`
*   **Ví dụ:** If you heat ice, it melts. (Nếu bạn đun nóng đá, nó sẽ tan chảy).

## 2. LOẠI 1 (FIRST CONDITIONAL)
*   **Cách dùng:** Diễn tả sự việc có thể xảy ra ở hiện tại hoặc tương lai nếu điều kiện được đáp ứng.
*   **Công thức:** `If + S + V1 (hiện tại đơn), S + will/can/may + V1 (nguyên mẫu)`
*   **Ví dụ:** If it rains, I will stay at home.

## 3. LƯU Ý VỀ "UNLESS"
`Unless = If ... not` (Trừ khi)
*   **Ví dụ:** Unless you study hard, you will fail.
*   **Tương đương:** If you don't study hard, you will fail.

## 4. BIẾN THỂ (VARIATIONS)
*   **Mệnh lệnh thức:** `If you see him, tell him to call me.` (Dùng V1 ở mệnh đề chính thay vì 'will').
*   **Dự đoán yếu:** Dùng `might` thay cho `will`.
