# CẤU TRÚC BỊ ĐỘNG ĐẶC BIỆT (SPECIAL PASSIVE STRUCTURES)

Các cấu trúc này cực kỳ phổ biến trong đề thi và Writing học thuật.

## 1. BỊ ĐỘNG VỚI 2 TÂN NGỮ (VERBS WITH 2 OBJECTS)
Các động từ: *give, send, show, buy, lend, tell...*
*   **Active:** `Somebody + give + Indirect Object (người) + Direct Object (vật)`
*   **Passive 1:** `Indirect Object + be + V3 + Direct Object`
*   **Passive 2:** `Direct Object + be + V3 + TO + Indirect Object`
*   *Ví dụ:* He gave me a flower.
    * -> I was given a flower.
    * -> A flower was given **to** me.

## 2. BỊ ĐỘNG KHÁCH QUAN (IMPERSONAL PASSIVE)
Dùng với các động từ tường thuật: *say, think, believe, report, rumor, know...*
*   **Dạng 1:** `It + be + V3 + that + Clause`
    * *Ví dụ:* It is said that he is a genius.
*   **Dạng 2:** `Subject (of clause) + be + V3 + TO-INFINITIVE / TO HAVE V3`
    * *Ví dụ:* He is said **to be** a genius.

## 3. CẤU TRÚC NHỜ VẢ (CAUSATIVE PASSIVE)
*   **Active:** `Have + someone + V1` / `Get + someone + TO V1`
*   **Passive:** `Have/Get + something + V3 (by someone)`
*   *Ví dụ:* I had the mechanic fix my car. -> I had my car **fixed**.

## 4. BỊ ĐỘNG VỚI ĐỘNG TRỪ GIÁC QUAN (SEE, HEAR, WATCH...)
*   **Active:** `See + someone + V-ing/V1`
*   **Passive:** `Someone + be + seen + V-ing/ TO V1`
*   *Ví dụ:* I saw him running. -> He was seen **running**.
