# ĐẠI TỪ VÀ TRẠNG TỪ QUAN HỆ (RELATIVE PRONOUNS & ADVERBS)

## 1. BẢNG TRA CỨU NHANH (RETRIEVAL LOOKUP)

| Đại từ / Trạng từ | Thay thế cho | Chức năng trong MĐQH | Cấu trúc đi kèm |
| :--- | :--- | :--- | :--- |
| **WHO** | Người | Chủ ngữ / Tân ngữ | `... N (người) + WHO + V/S+V` |
| **WHOM** | Người | Tân ngữ | `... N (người) + WHOM + S + V` |
| **WHICH** | Vật, sự vật | Chủ ngữ / Tân ngữ | `... N (vật) + WHICH + V/S+V` |
| **THAT** | Người + Vật | Chủ ngữ / Tân ngữ | Chỉ dùng trong MĐ xác định |
| **WHOSE** | Người / Vật | Sở hữu cách | `... N1 + WHOSE + N2 (không có the)` |
| **WHERE** | Nơi chốn | Trạng từ | `= in/on/at + which` |
| **WHEN** | Thời gian | Trạng từ | `= in/on/at + which` |
| **WHY** | Lý do | Trạng từ | `= for + which` |

## 2. ĐIỀU KIỆN BẮT BUỘC DÙNG "THAT"
Hệ thống kiểm tra tự động cần bắt được các token đi kèm trước danh từ:
*   Danh từ hỗn hợp gồm cả người lẫn vật (e.g., *the man and his dog*).
*   Sau dạng so sánh nhất (e.g., *the most beautiful*, *the best*).
*   Sau các tiền từ hạn định: *all, some, any, little, none, much, only*.
*   Sau các đại từ bất định: *something, someone, anything, nobody*.
