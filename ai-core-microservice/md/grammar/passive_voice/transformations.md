# MẪU CHUYỂN ĐỔI BỊ ĐỘNG (PASSIVE TRANSFORMATIONS)

Sử dụng các mẫu này để AI gợi ý người dùng chuyển từ câu chủ động sang câu bị động nhằm tăng tính học thuật (Academic Tone).

## 1. ACTIVE -> ACADEMIC PASSIVE (Band 7.0+)
*   **Source:** `People + [think/say/believe] + that + Clause`
*   **Template:** `It is + [thought/said/believed] + that + Clause`
*   **Ví dụ:**
    *   *Input:* People think that education is the key to success.
    *   *Transformation:* **It is thought that** education is the key to success.

## 2. ACTIVE -> CAUSATIVE PASSIVE (Nhờ vả)
*   **Source:** `Subject + ask + Someone + to fix + Something`
*   **Template:** `Subject + have + Something + fixed`
*   **Ví dụ:**
    *   *Input:* I asked the gardener to cut the grass.
    *   *Transformation:* I **had the grass cut**.

## 3. MODAL -> MODAL PASSIVE
*   **Source:** `Government + should + improve + Public transport`
*   **Template:** `Public transport + should + be + improved`
*   **Ví dụ:**
    *   *Input:* We should protect the environment.
    *   *Transformation:* The environment **should be protected**.

## 4. PROCESS DESCRIPTION (Writing Task 1)
*   **Template:** `First, [Material] + is + [Action_V3]`
*   **Ví dụ:**
    *   *Input:* First, workers pick the tea leaves.
    *   *Transformation:* First, the tea leaves **are picked**.
