# Cohesive Devices and Transitions

## Advanced Cohesion
Band 8 cohesion requires using transitions smoothly and naturally. Avoid mechanically dropping transition words at the start of every sentence (e.g., Firstly... Secondly... Finally...).

## Reference Words
Use pronouns (this, these, those, such) to link back to previous ideas without repeating the exact words. This demonstrates advanced cohesion.
Example: "Many cities face pollution. This problem can be addressed by..."

## Avoiding Memorized Templates
A highly debated issue whether X is beneficial or detrimental is a cliché template. Examiners penalize essays that use empty, memorized transitional phrases. Instead, develop specific ideas.
