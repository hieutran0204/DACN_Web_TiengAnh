# ỨNG DỤNG CÂU BỊ ĐỘNG TRONG IELTS (IELTS PASSIVE STRATEGIES)

Câu bị động là chìa khóa để đạt Band 7.0+ GRA (Grammatical Range) vì nó tạo ra sắc thái khách quan (Objectivity).

## 1. WRITING TASK 1 (PROCESS DIAGRAM)
Câu bị động là cấu trúc thống trị trong bài mô tả quy trình (Process).
*   **Active:** First, the machine grinds the coffee beans.
*   **Passive (Band 7.0+):** First, the coffee beans **are ground** by the machine.

## 2. WRITING TASK 2 (ACADEMIC TONE)
Sử dụng bị động để tránh dùng ngôi thứ nhất (I, we) hoặc những từ chung chung (People).
*   **Band 5.0:** People believe that technology is harmful.
*   **Band 7.0+:** **It is widely believed that** technology has detrimental effects on society.

## 3. CÁC ĐỘNG TỪ "ACADEMIC PASSIVE" NÊN DÙNG
| Active | Passive Equivalent (Highly Recommended) |
| :--- | :--- |
| People say | It is claimed / asserted that... |
| We should solve | This issue should be addressed / tackled... |
| They found out | It was discovered / established that... |
| We use this | This approach is utilized / employed... |
