# BIẾN ĐỔI BỊ ĐỘNG THEO THÌ (TENSE TRANSFORMATIONS)

Bảng quy tắc chuyển đổi từ câu Chủ động (Active) sang Bị động (Passive) dựa trên 12 thì cơ bản.

| Tense | Active Form | Passive Form (BE + V3) |
| :--- | :--- | :--- |
| **Present Simple** | `S + V1 + O` | `S + am/is/are + V3` |
| **Present Continuous** | `S + am/is/are + V-ing` | `S + am/is/are + BEING + V3` |
| **Present Perfect** | `S + have/has + V3` | `S + have/has + BEEN + V3` |
| **Past Simple** | `S + V2/ed + O` | `S + was/were + V3` |
| **Past Continuous** | `S + was/were + V-ing` | `S + was/were + BEING + V3` |
| **Past Perfect** | `S + had + V3` | `S + had + BEEN + V3` |
| **Future Simple** | `S + will + V1` | `S + will + BE + V3` |
| **Be going to** | `S + am/is/are + going to + V1` | `S + am/is/are + going to + BE + V3` |

## CÁC BƯỚC CHUYỂN ĐỔI (STEPS)
1.  **B1:** Lấy Tân ngữ (O) của câu chủ động làm Chủ ngữ (S) của câu bị động.
2.  **B2:** Chia động từ `BE` theo thì của động từ chính trong câu chủ động.
3.  **B3:** Đưa động từ chính về dạng `V3/ED`.
4.  **B4:** Thêm `by + Tác nhân` (nếu cần thiết).
    *   *Lưu ý:* Bỏ `by people, by someone, by them, by me...` nếu tác nhân không quan trọng hoặc không xác định.
