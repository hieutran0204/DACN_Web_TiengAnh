# BIẾN ĐỔI ĐẠI TỪ VÀ TRẠNG TỪ (PRONOUN & ADVERB CHANGES)

## 1. BIẾN ĐỔI ĐẠI TỪ (PRONOUNS)
Nguyên tắc: Đổi theo ngôi của người tường thuật.
*   `I` -> `he / she`
*   `We` -> `they`
*   `Me` -> `him / her`
*   `My` -> `his / her`

## 2. BIẾN ĐỔI TRẠNG TỪ THỜI GIAN/ĐỊA ĐIỂM
| Direct | Reported |
| :--- | :--- |
| **Now** | **Then** |
| **Today** | **That day** |
| **Yesterday** | **The day before / The previous day** |
| **Tomorrow** | **The next day / The following day** |
| **Last week** | **The week before / The previous week** |
| **Next month** | **The month after / The following month** |
| **Here** | **There** |
| **This / These** | **That / Those** |
| **Ago** | **Before** |
