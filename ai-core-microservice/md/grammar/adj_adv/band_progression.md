# ỨNG DỤNG TRONG IELTS (IELTS USAGE)

## 1. MÔ TẢ BIỂU ĐỒ (WRITING TASK 1)
So sánh là "linh hồn" của Task 1.
*   **Mẫu câu:** "The number of users in 2010 was **significantly higher than** that in 2005."
*   **Nhấn mạnh:** Dùng *much, far, significantly, slightly* đứng trước so sánh hơn.

## 2. LẬP LUẬN LOGIC (WRITING TASK 2)
Dùng so sánh kép để chỉ mối quan hệ nhân quả.
*   **Mẫu câu:** "**The more** a country invests in education, **the more developed** its economy will be."

## 3. LỖI DÙNG TÍNH TỪ MÔ TẢ (TASK 2)
Sử dụng tính từ mạnh thay vì dùng "very + adj".
*   *Weak:* Very big.
*   *Strong:* **Enormous / Massive**.
*   *Weak:* Very good.
*   *Strong:* **Excellent / Outstanding**.
