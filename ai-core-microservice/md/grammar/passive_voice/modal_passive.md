# BỊ ĐỘNG VỚI ĐỘNG TỪ KHIẾM KHUYẾT (MODAL PASSIVE)

Cấu trúc bị động dành cho các động từ khiếm khuyết (Modal Verbs) như *can, could, may, might, must, should, shall, will, would...*

## 1. CÔNG THỨC CHUNG (GENERAL FORM)
`MODAL + BE + V3/ED`

## 2. BẢNG TRA CỨU NHANH
| Modal Verb | Active Form | Passive Form |
| :--- | :--- | :--- |
| **Can / Could** | `can + V1` | `can + BE + V3` |
| **Must / Have to** | `must + V1` | `must + BE + V3` |
| **Should / Ought to** | `should + V1` | `should + BE + V3` |
| **May / Might** | `may + V1` | `may + BE + V3` |

## 3. CẤU TRÚC MODAL HOÀN THÀNH (MODAL PERFECT PASSIVE)
Dùng để diễn tả dự đoán hoặc lời khuyên về một sự việc đã xảy ra trong quá khứ.
*   **Active:** `Modal + HAVE + V3`
*   **Passive:** `Modal + HAVE + BEEN + V3`
*   **Ví dụ:** 
    *   They should have finished the work.
    *   -> The work **should have been finished**.

## 4. LƯU Ý VỚI "HAVE TO" VÀ "USED TO"
*   **Have to:** `S + have to + be + V3` (e.g., *This must be done*).
*   **Used to:** `S + used to + be + V3` (e.g., *This house used to be painted green*).
